AI Brain Developer Documentation

Integrate persistent long-term memory graphs and autonomous agents into Python or JavaScript applications.

*Note: SDK packages are distributed via private developer registries to waitlist members upon API key issuance.*

1. Installation & Package Spec

# Install Python SDK
pip install aibrain-sdk

# Install Node.js / TypeScript SDK
npm install @aibrain/sdk

2. Quickstart Code Example

from aibrain import AIClient

# Initialize client with your API key
client = AIClient(api_key="sk_live_aibrain_key")

# Query persistent memory graph
memory = client.memory.retrieve(
    user_id="user_101", 
    query="Project architecture notes"
)

# Dispatch Research Agent with memory context
result = client.agents.dispatch(
    role="research",
    prompt="Synthesize context into executive report",
    context=memory
)

print(result.summary)
